# 长护师刷题小程序前端功能说明

## 1. 页面结构

### 首页 `pages/index/index`

首页是用户进入后的主功能入口。

页面内容：

- 顶部展示应用名称：`我爱刷题`
- 展示当前题库标题，例如：`长期照护师初级考题`
- 展示题库信息：
  - 作者
  - 更新时间
  - 当前等级题目总数
- 等级下拉框：
  - 初级五级
  - 初级四级
  - 初级三级
  - 初级二级
  - 初级一级
  - 中级四级
  - 中级三级
  - 中级二级
  - 中级一级
  - 高级三级
  - 高级二级
  - 高级一级
- 题型切换：
  - 选择题
  - 判断题
- 功能入口：
  - 顺序练习
  - 随机练习
  - 模拟考试
  - 我的错题
  - 试题搜索

首页接口：

```http
GET /api/home
```

进入首页时：

- 如果没有登录，先调用微信登录。
- 如果已登录，直接请求首页数据。
- 如果 `hasPaid = false`，点击答题相关入口时先弹出购买提示。

## 2. 登录流程

### 微信登录

小程序启动或进入首页时调用：

```js
wx.login({
  success(res) {
    // res.code 发送给后端
  }
})
```

后端接口：

```http
POST /api/auth/wechat-login
```

请求：

```json
{
  "code": "wx.login返回的code",
  "nickname": "用户昵称",
  "avatarUrl": "头像地址"
}
```

响应：

```json
{
  "token": "JWT",
  "user": {
    "id": 1,
    "nickname": "张三",
    "avatarUrl": "...",
    "hasPaid": true
  }
}
```

前端处理：

- 保存 `token` 到 `wx.setStorageSync('token', token)`
- 保存用户信息到本地
- 后续所有需要登录的接口都带请求头：

```http
Authorization: Bearer <token>
```

## 3. 付款流程

所有答题相关功能都需要付款后才能使用：

- 顺序练习
- 随机练习
- 模拟考试
- 我的错题
- 试题搜索

点击这些入口时：

- 如果 `hasPaid = true`，正常进入。
- 如果 `hasPaid = false`，弹窗提示一次性购买。

创建支付订单：

```http
POST /api/pay/orders
```

请求：

```json
{
  "product": "full_access"
}
```

响应：

```json
{
  "orderNo": "20260511123456789",
  "payParams": {
    "timeStamp": "...",
    "nonceStr": "...",
    "package": "prepay_id=...",
    "signType": "RSA",
    "paySign": "..."
  }
}
```

前端调用微信支付：

```js
wx.requestPayment({
  timeStamp,
  nonceStr,
  package: packageValue,
  signType,
  paySign,
  success() {
    // 重新调用 /api/home 或重新登录，刷新 hasPaid
  },
  fail() {
    // 提示支付未完成
  }
})
```

## 4. 顺序练习

页面建议：`pages/practice/sequence`

功能：

- 按当前等级、当前题型顺序展示题目。
- 支持上一题、下一题。
- 支持选择答案后提交。
- 提交后显示：
  - 正确 / 错误
  - 正确答案
  - 解析

接口：

```http
GET /api/questions/sequence?levelId=1&type=single_choice&page=1&pageSize=20
```

题型参数：

- `single_choice`：选择题
- `true_false`：判断题

提交答案：

```http
POST /api/questions/{questionId}/answer
```

请求：

```json
{
  "answer": "A",
  "mode": "sequence"
}
```

判断题答案：

```json
{
  "answer": "true",
  "mode": "sequence"
}
```

响应：

```json
{
  "correct": true,
  "correctAnswer": "A",
  "analysis": "题目解析",
  "wrongCount": 0
}
```

## 5. 随机练习

页面建议：`pages/practice/random`

功能：

- 根据当前等级、当前题型随机获取题目。
- 默认一次获取 20 题。
- 答题逻辑和顺序练习一致。

接口：

```http
GET /api/questions/random?levelId=1&type=single_choice&limit=20
```

提交答案接口同顺序练习：

```http
POST /api/questions/{questionId}/answer
```

请求时 `mode` 使用：

```json
{
  "answer": "A",
  "mode": "random"
}
```

## 6. 模拟考试

页面建议：

- `pages/exam/start`
- `pages/exam/detail`
- `pages/exam/result`

规则：

- 每次考试 100 题。
- 80 道选择题。
- 20 道判断题。
- 每题 1 分，总分 100 分。
- 倒计时 1 小时。
- 倒计时以前端展示为主，但最终以后端时间为准。

创建考试：

```http
POST /api/exams
```

请求：

```json
{
  "levelId": 1
}
```

响应：

```json
{
  "examId": 88,
  "durationSeconds": 3600,
  "startedAt": "2026-05-11T14:00:00",
  "questions": [
    {
      "id": 1001,
      "order": 1,
      "type": "single_choice",
      "content": "题干",
      "options": ["A内容", "B内容", "C内容", "D内容"]
    }
  ]
}
```

前端处理：

- 创建考试后进入答题页。
- 本地保存：
  - `examId`
  - `startedAt`
  - `durationSeconds`
  - `questions`
  - 用户已选答案
- 显示倒计时。
- 用户可以切换题号。
- 用户点击交卷或倒计时结束时提交。

提交考试：

```http
POST /api/exams/{examId}/submit
```

请求：

```json
{
  "answers": [
    {
      "questionId": 1001,
      "answer": "A"
    },
    {
      "questionId": 1002,
      "answer": "true"
    }
  ]
}
```

响应：

```json
{
  "examId": 88,
  "score": 92,
  "totalScore": 100,
  "usedSeconds": 2380,
  "durationSeconds": 3600,
  "submittedAt": "2026-05-11T14:39:40",
  "details": [
    {
      "questionId": 1001,
      "correct": true,
      "correctAnswer": "A",
      "analysis": "解析"
    }
  ]
}
```

结果页展示：

- 得分
- 总分
- 使用时间
- 正确题数
- 错误题数
- 每道题的正确答案和解析

考试历史：

```http
GET /api/exams/history?levelId=1&page=1&pageSize=20
```

## 7. 我的错题

页面建议：`pages/wrong/index`

功能：

- 展示用户历史答错过的题。
- 支持按等级筛选。
- 支持按题型筛选。
- 题目展示和练习页一致。
- 可重新答题。

接口：

```http
GET /api/wrong-questions?levelId=1&type=single_choice&page=1&pageSize=20
```

响应内容包含：

- 题目 ID
- 题干
- 选项
- 错误次数
- 最近答题时间

## 8. 试题搜索

页面建议：`pages/search/index`

功能：

- 输入关键词搜索题干。
- 支持按等级筛选。
- 支持按题型筛选。
- 点击搜索结果进入题目详情。

接口：

```http
GET /api/questions/search?levelId=1&type=single_choice&keyword=护理&page=1&pageSize=20
```

前端规则：

- 关键词为空时不请求接口。
- 搜索结果不直接显示答案。
- 点击题目后可以答题，提交后显示答案和解析。

## 9. 公共请求封装

建议封装 `utils/request.js`：

功能：

- 自动拼接 `baseUrl`
- 自动带 `Authorization`
- 统一处理 401：
  - 清除本地 token
  - 重新登录
- 统一处理 403：
  - 如果接口返回“请先付款后再答题”，弹出购买弹窗
- 统一处理接口错误提示

示例：

```js
const BASE_URL = 'http://localhost:8080'

function request(options) {
  const token = wx.getStorageSync('token')
  return new Promise((resolve, reject) => {
    wx.request({
      url: BASE_URL + options.url,
      method: options.method || 'GET',
      data: options.data || {},
      header: {
        'content-type': 'application/json',
        ...(token ? { Authorization: `Bearer ${token}` } : {})
      },
      success(res) {
        if (res.statusCode >= 200 && res.statusCode < 300) {
          resolve(res.data)
        } else {
          wx.showToast({
            title: res.data?.message || '请求失败',
            icon: 'none'
          })
          reject(res)
        }
      },
      fail: reject
    })
  })
}

module.exports = request
```

## 12. 页面跳转建议

首页入口对应跳转：

```text
顺序练习 -> /pages/practice/sequence/index
随机练习 -> /pages/practice/random/index
模拟考试 -> /pages/exam/start/index
我的错题 -> /pages/wrong/index
试题搜索 -> /pages/search/index
```

模拟考试内部：

```text
/pages/exam/start/index
  -> /pages/exam/detail/index?examId=88
  -> /pages/exam/result/index?examId=88
```

## 13. 重要交互规则

- 未登录用户先自动微信登录。
- 未付款用户不能进入答题、考试、错题、搜索。
- 题目列表接口不显示答案。
- 只有提交答案后才显示正确答案和解析。
- 模拟考试开始后前端倒计时 1 小时。
- 模拟考试交卷后不能再次修改答案。
- 答错题目自动进入“我的错题”。
- 等级和题型切换后，首页统计和题目列表都要重新请求。
